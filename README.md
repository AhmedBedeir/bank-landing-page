# Bank Landing Page

A modern, responsive landing page built with **React** and **Tailwind CSS**.  
Designed for fintech startups and banking services, this project demonstrates clean UI, reusable components, and a developer-friendly structure.

## 🚀 Features

- 💡 Fully responsive design
- ♻️ Reusable React components
- 🎨 Styled with Tailwind CSS
- ⚡ Fast and lightweight
- 📱 Mobile-first approach
- 🧩 Modular file structure for scalability

## 🛠️ Tech Stack

- React
- Tailwind CSS
- JavaScript (ES6+)
